# Telegram গ্রুপ ম্যানেজার বট 🤖

তোমার গ্রুপ চালানোর বট — ফ্রিতে Render-এ চলবে।

## বট যা যা করবে

| কাজ | কীভাবে |
|---|---|
| 👋 নতুন মেম্বারকে স্বাগতম | জয়েন করলেই নিয়মসহ ওয়েলকাম মেসেজ |
| 🚫 লিংক/স্প্যাম বন্ধ | মেম্বার লিংক দিলে মেসেজ মুছে ওয়ার্নিং দেবে |
| 🤬 খারাপ শব্দ ফিল্টার | গালি থাকলে মেসেজ মুছে ওয়ার্নিং দেবে |
| ⛔ ৩ বার ওয়ার্নিং = মিউট | ৩ বার নিয়ম ভাঙলে ১ ঘণ্টা মিউট |
| 🛒 গ্রুপ কেনার মেসেজ | কেউ "কিনতে চাই / buy / দাম" লিখলে উত্তর দেবে: **গ্রুপ কিনতে মেসেজ করুন @তোমার_ইউজারনেম** |
| /buy কমান্ড | /buy লিখলেই কেনার তথ্য দেবে |
| /rules কমান্ড | গ্রুপের নিয়ম দেখাবে |
| /warn কমান্ড | অ্যাডমিন কারো মেসেজে রিপ্লাই দিয়ে /warn লিখলে ওয়ার্নিং দেবে |

## ধাপ ১: বট বানাও (২ মিনিট)

1. Telegram-এ **@BotFather** খোলো
2. `/newbot` লেখো → বটের নাম দাও → ইউজারনেম দাও (শেষে `bot` থাকতে হবে, যেমন `CineViralGroupBot`)
3. BotFather একটা **Token** দেবে — ওটা কপি করে রাখো
4. ⚠️ Token কাউকে পাঠাবে না, আমাকেও না — ওটা বটের পাসওয়ার্ড

## ধাপ ২: কোড GitHub-এ তোলো

1. [github.com](https://github.com) এ গিয়ে **New repository** বানাও (নাম: `telegram-group-bot`, Public)
2. এই ফোল্ডারের ৩টা ফাইল আপলোড করো: `bot.py`, `requirements.txt`, `render.yaml`

## ধাপ ৩: Render-এ ফ্রিতে চালু করো

1. [render.com](https://render.com) এ গিয়ে GitHub দিয়ে সাইন ইন করো
2. **New + → Web Service** → তোমার `telegram-group-bot` রিপো বেছে নাও
3. **Plan: Free** বেছে নাও, **Create Web Service** চাপো
4. প্রথমে ডিপ্লয় হবে, তারপর Render একটা লিংক দেবে — যেমন `https://telegram-group-bot-xxxx.onrender.com` — ওটা কপি করো
5. বাম মেনুতে **Environment** এ গিয়ে এই ৩টা বসাও:

| Key | Value |
|---|---|
| `BOT_TOKEN` | BotFather-এর Token (ধাপ ১-এর) |
| `ADMIN_USERNAME` | তোমার Telegram ইউজারনেম (@ ছাড়া) |
| `WEBHOOK_URL` | Render-এর লিংক (ধাপ ৪-এর) |

6. **Save Changes** চাপো — Render নিজে আবার চালু হবে, বট লাইভ!

## ধাপ ৪: বটকে গ্রুপে অ্যাডমিন বানাও

1. গ্রুপ খুলে বটের ইউজারনেম সার্চ করে অ্যাড করো
2. বটের নামে ট্যাপ করে **Promote to Admin** করো
3. এই পারমিশনগুলো চালু করো:
   - ✅ Delete Messages
   - ✅ Ban Users
   - ✅ Pin Messages (ঐচ্ছিক)

পারমিশন না দিলে বট মেসেজ মুছতে বা মিউট করতে পারবে না।

## নিজের মতো বদলাতে চাইলে

- **তোমার ইউজারনেম:** শুধু Render-এর `ADMIN_USERNAME` বদলাও, কোডে হাত দিতে হবে না
- **ওয়েলকাম মেসেজ / নিয়ম:** `bot.py`-এর `WELCOME_TEXT` বদলাও
- **খারাপ শব্দ:** `bot.py`-এর `BAD_WORDS` তালিকায় শব্দ যোগ করো
- **কেনার শব্দ:** `BUY_WORDS` তালিকায় শব্দ যোগ করো

## নিজের কম্পিউটারে পরীক্ষা করতে চাইলে

```bash
pip install -r requirements.txt
BOT_TOKEN=তোমার_টোকেন ADMIN_USERNAME=তোমার_ইউজারনেম python bot.py
```

(WEBHOOK_URL না দিলে polling মোডে চলবে — কম্পিউটার বন্ধ করলেই বট বন্ধ হবে, তাই আসল চালানোর জন্য Render-ই ভালো।)
